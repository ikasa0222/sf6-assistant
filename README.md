# 街霸6助手 (SF6 Assistant)

专为《街头霸王6》（Street Fighter 6）格斗玩家打造的本地战绩管理、对策复盘与数据分析工具。

支持 Android 平台，纯本地优先架构，无需自建服务器，直连卡普空官方数据源。

---

## 为什么写这个工具

玩街霸6的玩家大概都遇到过这几个痛点：

1. 卡普空官方网站（Buckler's Boot Camp）上的战绩回放只给看最近的 100 场。多打几把排位，前几天的复盘对局就被顶没了，想回顾自己是怎么一步步爬上大师、或者看以前被某个角色暴打的记录根本查不到。
2. 官方网页端在手机上用起来很繁琐，查帧数、看好友状态、看俱乐部积分每次都要重新翻网页，加载慢，排版也不适合手机屏幕。
3. 遇到打不明白的角色，想查一下某个必杀技被防到底是不是确反、能确反多少帧，手头没有顺手且离线可用的中文帧数工具。

街霸6助手就是为了解决这些问题而写的。把官方数据抓取到手机本地 SQLite 数据库永久保存，不设 100 场上限，所有分析和笔记都在你自己的手机里，换机还能导出导入备份。

---

## 真实核心功能

### 1. 突破官方 100 场限制的战绩库
- 永久本地归档：每次同步采用增量写入，只追加新对局，绝不删减旧历史。打过 500 场、1000 场都会踏踏实实躺在本地数据库里。
- 完整战况解析：每场对战记录精确到对局时间、双方角色、双方当前 LP/MR、分段变动、对手平台、操作方式（经典 C / 现代 M）、单回合结算方式（CA、Perfect、KO）。
- 回放代码与海报分享：一键提取并复制对局 Replay Code，在游戏内直接看录像；支持生成高颜值战绩长图海报分享给群友。
- 多维度筛选：支持排位赛、休闲赛、格斗中心、自建房分模式查看；支持展开按角色筛选，清楚展示每个角色打过的实际场次和对应胜率。

### 2. 首页数据看板与全角色天梯榜
- 生涯与近期走势：直观展示总胜率、总对局数、当前连胜、历史最高连胜，以及最近 20 场的胜率分布和近 10 局的 W/L 战况走势。
- 升段目标估算：根据当前 LP 自动计算距离下一阶梯所需的净胜场次，并标注大师分（MR）评分。
- 多角色独立积分榜：自动罗列账号下所有打过排位的角色积分与胜率，点击即可一键切换当前关注的主玩角色。
- 战斗六维评估：基于官方打法雷达图，可视化展示压制进攻、确反防守、精准对空、斗气管理、连段技术等能力维度。

### 3. 深度数据分析与克制矩阵
- 双轨对策数据：支持一键切换「官方全角色克制榜」与「本地实战复盘统计」。既能看卡普空全网统计的大数据克制关系，也能看你个人在实战中面对特定角色的真实胜率。
- MR 走势图表：直观呈现大师分的起伏曲线，哪天在稳定上分、哪天在状态低迷一目了然。

### 4. 社交圈子与玩家深度档案
- 俱乐部成员天梯：实时同步所属战队的全部成员列表、在线状态、月度贡献度点数以及各成员段位。
- 玩家二级主页：点击任何好友或战队成员，可调出其独立资料页，查看对方的公开战绩、各角色排位表现，以及你与对方的历史正面对决交手记录（Head-to-Head）。
- 跨平台标识统一：自动识别 PC (Steam)、PlayStation (PS5/PS4)、Xbox Series X|S，以及任天堂最新平台统一显示为 NS2，不再出现同一平台标签混乱的情况。

### 5. 官方全量角色发生帧数表与对策笔记
- 收录全角色数据：包含隆、肯、豪鬼、卢克、嘉米、春丽、维加、特瑞、不知火舞、艾莲娜、沙加特等 33+ 位角色的官方原画头像与完整技能帧数。
- 快速检索与过滤：支持按发生帧数、防御硬直差、伤害排序，一键筛选出「被防有利」进攻技和「被防大确反」招式。
- 对策笔记本：针对特定角色（例如针对豪鬼波升对策）或特定玩家（比如记下经常在武道馆碰到的熟人起手习惯）编写专属心得。

### 6. 本地全量数据备份与恢复
- 本地导出备份：一键将本地 SQLite 里的所有对局记录、对策笔记、关注好友和账号配置导出为标准 JSON 文件。
- 双重保存通道：自动保存至手机公共 Download/SF6_Assistant_Backups/ 目录，同时拉起系统分享面板，方便将备份直接发给自己的微信、QQ、网盘或存到手机任意文件夹。
- 增量恢复机制：换手机或重装应用后，可直接选择本地备份文件或粘贴 JSON 数据进行恢复，自动按对局主键增量合并，老数据和新数据无缝共存。

### 7. 账号管理与更新诊断
- 多账号与无感同步：支持绑定多个 Capcom ID 或通过 10 位 Short ID 快速绑定，已登录账号支持后台静默增量刷新。
- 内置版本更新检查：对接 GitHub Releases，每天首次打开自动静默检查，也可在设置里手动检测，支持国内镜像源高速下载。
- 全局抓包诊断黑匣子：内置网络抓包与异常拦截控制台，遇到网络或解析问题可一键复制排查报告，不抓瞎。

## 隐私与安全

- 本地优先（Local-First）：本软件为纯客户端单机运行，没有也不需要自己的后台服务器，绝不上传你的密码、会话凭证或对战记录到任何第三方平台。
- 凭证本地安全存储：官方登录 Cookie 会话使用 Android Keystore 加密存储（flutter_secure_storage），仅用于向卡普空官方网站请求数据。

## 本地编译与构建

如果你想自己从源码编译构建 APK：

### 环境要求
- Flutter SDK (>= 3.0.0)
- Android SDK (API Level >= 21)
- JDK 17

### 常用命令
```bash
# 1. 克隆仓库
git clone https://github.com/OldSea/SF6_Assistant.git
cd SF6_Assistant

# 2. 获取依赖包
flutter pub get

# 3. 运行测试套件 (包含 17 项完整单元测试)
flutter test

# 4. 编译推荐安装包 (针对主流 64 位手机深度优化，体积约 25MB)
flutter build apk --release --split-per-abi --android-skip-build-dependency-validation

# 5. 编译通用兼容包 (包含全 CPU 架构，体积约 61MB)
flutter build apk --release --android-skip-build-dependency-validation
```

编译产物说明：
- 推荐安装包：`build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`（约 25.0 MB，推荐大多数 Android 用户使用）
- 通用完整包：`build/app/outputs/flutter-apk/app-release.apk`（约 61.2 MB）
