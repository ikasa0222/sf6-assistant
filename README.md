## 📖 为什么开发这个工具

玩《街霸6》的格斗玩家日常几乎都会遇到以下痛点：

1. **官方 100 场限制与复盘断流**：卡普空官方网站（Buckler's Boot Camp）仅保留最近的 100 场对局。排位打得稍多一点，几周甚至几天前的录像和关键对局就被顶替清除了。想复盘自己由钻入魔的心路历程、或者查找曾经被某个特定对手击败的对局根本无从查起。
2. **手机端查阅繁琐与网络迟滞**：官方网页端在手机浏览器排版拥挤，查帧数、看好友状态、看战队积分每次都需要漫长翻找与重新授权，体验极差。
3. **缺乏顺手的离线中文帧数与变种工具**：实战中遇到打不明白的必杀技，想立刻搞清楚轻/中/重/OD四个版本的具体发生帧、被防差以及有无无敌判定，手头没有兼备 100% 离线、中文对照与变种区分的权威工具。
4. **对战录像代码使用门槛高**：想去游戏里观看某个对手的录像，缺乏一键复制和游戏内检索的直观指引。

**街霸6助手**正是为此而生——采用**本地优先（Local-First）**架构，把官方数据直接抓取到手机本地 SQLite 数据库永久持久化，**突破官方 100 场限制**，提供 31 全角色权威离线帧数库、实用连招指南、排位走势图表与首页卡片拖拽自定义，所有数据与对策心得完全掌控在玩家自己手中。

## 🥊 核心功能特性

### 1. 突破官方 100 场限制的战绩库 (Match History)
- **永久本地增量归档**：每次同步采用主键增量写入，只追加新对局，绝不删减旧历史。500 场、1000 场乃至上万场战绩安全沉淀在手机本地。
- **全要素战况精细解析**：精准提取对局时间、双方角色、实时 LP/MR、分段升降差额、操作方式（经典 C / 现代 M）、单回合结算徽章（CA、Perfect、KO）、硬件平台（Steam、PS5、Xbox、NS2）。
- **对战录像代码 (Replay Code) 深度集成**：卡片直接提取回放代码并支持一键复制，内置游戏内 CFN 检索 5 步详细指引弹窗。
- **战报长图海报导出与分享**：一键生成对战结算高清战报长图，支持系统原生多渠道分享与剪贴板复制。
- **多维度筛选过滤**：支持排位赛、休闲赛、比赛间对战、格斗中心对战独立查看；支持角色独立胜率看板。

### 2. 首页排位走势折线图与卡片拖拽管理 (Dashboard)
- **排位分数走势折线图 (Ranked Trend Chart)**：
  - **多时间跨度**：支持 `近20场`、`近100场`、`全部` 自由切换，采用紧凑型展开二级菜单 (`PopupMenuButton`)，窄屏设备 100% 适配无任何像素溢出；
  - **主玩角色即时联动**：主玩角色切换后折线图自适应跟随；若当前主玩角色排位场次 $<2$ 场，自动展示赛博风格友好占位面板引导（*“【角色名】暂无排位赛记录，进行 2 场以上排位赛即可生成走势图”*）；
  - **官方段位色彩刻度**：Y 轴刻度数字根据当前分数段位（大师明金、钻石青蓝、白金青绿等）动态赋予专属配色。
- **首页 7 大核心卡片显隐与拖拽排序自定义**：
  - 在【设置 -> 首页卡片管理】中通过 `ReorderableListView` 支持手指拖拽自由重排 7 大卡片（玩家主页资料、排位走势、角色天梯榜、近期对局状态、最爱角色与时长、快速统计、能力雷达）；
  - 支持 `Switch` 单独开启或隐藏卡片，`hero` 玩家资料卡片强制常驻锁定，支持一键「恢复默认设置」。

### 3. 31 全角色权威官方帧数表与四版本变种 (Frame Data)
- **31 全角色完备阵容**：收录卡普空官方、FAT、Supercombo 权威数据源，完整支持包含 **沙加特 (Sagat)、C. 毒蛇 (C.Viper)、亚历克斯 (Alex)、英格丽德 (Ingrid)、亚斯敏 (Yasmine)** 在内的 31 位角色，每角色配备 50+ 真实招式。
- **必杀技轻/中/重/OD真实四版本独立重构**：
  - 彻底根除虚假数学估算，建立 `MoveVariation` 强类型模型；
  - 升龙拳、波动拳、猛虎升龙破等核心必杀技独立呈现各版本发生帧、持续帧、硬直帧、被防帧差、命中差及伤害（如升龙拳 OD 版 6F 发生、-40F 被防大确反、1-8F 完全无敌、单发伤害 1600）；
  - 招式详情变种表高保真着色：L 轻蓝、M 中金、H 重红、OD 紫。
- **100% 离线优先**：打包内置 2.1 MB 离线结构化数据 (`assets/data/sf6_framedata.json`)，零网络依赖，0ms 秒开。

### 4. 实用连招速查库与四模式指令渲染 (Combos & Commands)
- **离线连招深度治理**：基于 Supercombo Wiki 深度清洗，剔除乱码、表头污染与错位字段；
- **标准化起手分类**：规范收敛为 6 大标准中文起手标签（`确反康`、`斗气迸发`、`绿冲起手`、`打断康`、`普通命中`、`版边崩防`）；
- **四模态指令渲染引擎 (`Sf6CommandView`)**：
  - `graphic`（街霸官方原生图形图标：彩色拳脚图标 + 方向指示箭头）
  - `numpad`（经典数字简记法，如 `5LP`, `2MK`, `236P`）
  - `chinese`（中文通俗全称，如 `站轻拳`, `蹲中脚`, `波动拳`, `升龙拳`）
  - `modern`（现代模式彩色胶囊徽章流：`L`, `M`, `H`, `SP`, `AUTO`）
- **招式资源消耗精准呈现**：普通必杀技 0 气消耗、OD 必杀技 2 格斗气绿色方块、超必杀技呈现 SA 1~3 槽阶梯胶囊。

### 5. 判定框图谱与逐帧播放器 (Hitbox Viewer)
- **打击/受击判定图谱**：精准展示招式的攻击判定（红框）、受击判定（绿框）与本体位置；
- **高阶逐帧播放器**：具备播放/暂停切换、多档变速调节（`0.25x` / `0.5x` / `1.0x`）、关键帧锚点（起手 1F、发生点、收招点）瞬移步进。

### 6. 卡普空官方「最爱内容 / 模式游玩时长」真实接入 (Playtime)
- **100% 真实秒数逆向解析**：解构官方前端逻辑，彻底废除按对局数乘以 160 秒的失真估算，直连卡普空底层 `play.base_info.content_play_time_list`；
- **官方 Top 3 模式占比**：以官方配色比例条与格式化时长（如「120小时30分」）直观展现最爱玩法；
- **四大模式生涯场次看板**：完整呈现排位赛、比赛间、休闲赛、格斗中心真实生涯战绩。

### 7. 社交圈子与全网玩家搜索 (Social & Search)
- **全网玩家多模态检索**：支持 10 位 Short ID 极速直达、Fighter ID 关键字全网搜索，集成好友、战队与本地对局联想；
- **战队动态天梯**：实时掌握俱乐部全体成员在线状态、月度贡献度点数与各成员段位；
- **玩家二级主页**：查看对方公开战绩与角色表现，支持查询与对方的**历史正面对决交手记录（Head-to-Head）**。

### 8. 多账号无感切换与本地安全备份 (Multi-Account & Backup)
- **多账号与无感秒切**：支持绑定多个 Capcom ID 或多平台账号，首页与设置页一键秒切当前活跃档案；
- **全量 JSON 备份与增量恢复**：一键将本地 SQLite 全部战绩、笔记与配置导出为标准 JSON，支持直接保存至公共 Download 目录或唤起系统分享；换机导入自动根据对战主键增量去重合并；
- **隐私安全第一**：纯客户端单机运行，无任何自建后端，会话凭证使用 Android Keystore 原生加密（`flutter_secure_storage`）。

### 9. 应用内更新与全局诊断黑匣子 (Update & Diagnostics)
- **应用内 GitHub Release 更新**：每日启动自动静默检测，支持 **国内高速镜像通道 (`ghproxy.net`)** 与 GitHub 官方通道；
- **全局网络诊断控制台**：内置网络抓包与异常拦截日志系统，遇到任何同步异常可一键生成脱敏诊断报告。

街霸6助手为 iOS 用户提供未签名 `.ipa` 安装包（`SF6_Assistant_vX.X.X.X_unsigned.ipa`），您可通过以下方案之一在 iPhone / iPad 上免越狱侧载安装：

#### 方案 A: 巨魔商店 (TrollStore) —— 【最推荐 · 永久使用 · 免越狱】
- **适用系统与设备**:
  - iOS 14.0 ~ 15.8.3 (全机型)
  - iOS 16.0 ~ 16.6.1 (全机型)
  - iOS 17.0 (部分支持机型)
- **安装步骤**:
  1. 在 [GitHub Releases](https://github.com/OldSea/SF6_Assistant/releases) 页面下载 `SF6_Assistant_vX.X.X.X_unsigned.ipa`；
  2. 使用 Safari 浏览器下载后，点击分享按钮，选择【通过 TrollStore 打开】；
  3. 点击【Install】，秒级安装完成！
  4. **核心优势**: **永久有效**、无需证书、永不掉签、免越狱、无电脑即可安装。

#### 方案 B: 电脑工具自签 (Sideloadly / 爱思助手) —— 【全系统支持 · 7天自签】
- **适用设备**: iOS 12.0 ~ iOS 18.x 全版本 iOS 设备（无需越狱，需电脑辅助自签）。
- **使用 Sideloadly (强烈推荐，支持 Windows & macOS)**:
  1. 电脑端下载并安装 [Sideloadly 官方客户端](https://sideloadly.io/)；
  2. 使用数据线将 iPhone 连接至电脑，在手机上点击“信任此电脑”；
  3. 打开 Sideloadly，将下载的 `.ipa` 文件拖拽至左侧 IPA 图标区；
  4. 在【Apple ID】输入框中输入您的个人 Apple ID 邮箱（免费个人账号即可）；
  5. 点击【Start】，根据提示输入 Apple ID 密码（仅用于与苹果服务器通信申请免费证书，安全可靠）；
  6. 等待进度条达到 100% (Done)，手机桌面上即会出现【街霸6助手】图标。
- **使用爱思助手 (备选方案)**:
  1. 电脑安装爱思助手客户端，使用数据线连接 iPhone 并完成配对；
  2. 进入【工具箱】->【IPA 签名】-> 点击【添加 IPA】选择下载的 IPA 文件；
  3. 勾选【使用个人 Apple ID 签名】，添加您的 Apple ID 凭据并执行签名；
  4. 签名成功后在【应用游戏】列表中点击安装签名后的应用。

#### ⚠️ 安装后首次打开必看：
1. **信任证书**:
   - 进入手机【设置】->【通用】->【VPN 与设备管理】；
   - 在“开发者 App”下方点击您的 Apple ID，点击【信任】。
2. **开启开发者模式 (仅 iOS 16 及更高系统)**:
   - 进入手机【设置】->【隐私与安全性】-> 滑动到底部找到【开发者模式】(Developer Mode)；
   - 开启开关，按系统提示【重启手机】，开机后点击【开启】并输入锁屏密码。

#### 🔄 关于 7 天到期续签与数据保留说明：
- **免费个人 Apple ID 签名有效期为 7 天**。7 天到期后打开应用可能提示“无法验证应用”；
- **续签操作**: 无需卸载！只需将手机重新连上电脑，用 Sideloadly 或爱思助手重新覆盖安装一次即可；
- **数据绝对安全**: 重新覆盖安装**绝不会丢失任何本地历史战绩、对策笔记与配置数据**（本地 SQLite 数据库与用户配置永久受系统沙盒保护，不会丢失）。

#### ❓ 常见问题 FAQ:
- **Q: 提示“无法验证应用”或闪退？**  
  A: 请检查是否开启了 iOS 16+ 的【开发者模式】，并确保在【VPN 与设备管理】中信任了对应证书。
- **Q: 为什么不能直接上架 App Store？**

## 🛠️ 本地编译与构建

如果你想自行从源码编译 APK 安装包：

### 环境要求
- **Flutter SDK**：`>= 3.0.0`
- **Dart SDK**：`>= 3.0.0`
- **Android SDK**：API Level `>= 21` (Android 5.0+)
- **JDK**：`17`

### 构建步骤
```bash
# 1. 克隆代码仓库
git clone https://github.com/OldSea/SF6_Assistant.git
cd SF6_Assistant

# 2. 拉取 Flutter 依赖包
flutter pub get

# 3. 运行全量单元测试与回归套件 (106 项测试全部通过)
flutter test

# 4. 编译正式版 Release 安装包
flutter build apk --release --android-skip-build-dependency-validation
```

编译产物路径：
- `build/app/outputs/flutter-apk/app-release.apk` (体积约 64.2 MB)
